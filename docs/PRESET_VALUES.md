# 樹種プリセットの値（全項目）

`tools/dump_params.py` が `tree_forge/presets/*.json` から生成します（直接編集しないでください）。
**太字**は、その項目の既定値と違う値（その樹種で調整してある項目）です。項目の意味・範囲は [PARAMETERS.md](PARAMETERS.md) を見てください。
値の出所（図鑑・DB の記載値か推定値か）は、各 JSON の `_src` に書いてあります。**分枝角・頂芽優勢・重力屈性・垂れ・L2/L3 の値はすべて推定値**です。
