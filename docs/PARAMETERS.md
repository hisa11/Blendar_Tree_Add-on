# 設定項目一覧

`tools/dump_params.py` が `tree_forge/schema.py` から生成します（直接編集しないでください）。
樹種プリセットを選ぶと、これらの値がまとめて入れ替わります（`tree_forge/presets/*.json`）。

## どこに表示されるか

- **N パネル「TreeForge」（主パネル）**: 樹種、シード、品質、樹高、樹冠幅、胸高直径（自動のとき）、樹冠形、季節、**葉の量**、樹齢感、葉の表現。
- **サブパネル**: 「幹の太さ」（自動/指定、テーパー、太さの点列）、「いびつさ・損傷」（断面の歪み、折れ枝、垂れ下がり折れ、枯れ枝、枝下の枝痕）、「葉・花」。
- **「詳細モード」をオンにしたときだけ**: 折れ位置・頂部折れ、葉の細目（針束の本数・大きさのばらつき・幅・**葉を付ける枝・葉の付き始め・葉の最大数**・樹皮タイプ）、「詳細: 全体・幹」、「詳細: 枝 L1 / L2 / L3」。
- **「マテリアル」パネル**: 部位別の材質、樹皮タイルの実寸、UV の整数巻き、分岐ブレンド長。

このほかに、太さプロファイルの点列（高さ比・直径 cm）、葉オブジェクト（任意オブジェクト用）、部位別マテリアル（幹・枝・小枝・葉・花・果実・根張り・折れ口）、
「自動再生成」があります。
