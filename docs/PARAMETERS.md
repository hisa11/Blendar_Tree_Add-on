# 設定項目一覧（全項目）

`tools/dump_params.py` が、コードとプリセット JSON から生成します（**直接編集しないでください**）。
パネルの表示は、画面の描画コードを設定を変えながら実際に呼んで記録した結果です。

- パラメータ 96 項目（第 2 章）、UI 専用の設定、ボタン 15 個、品質 3 段階、樹種プリセット 13 種、参道シーンのオプション。
- 樹種ごとの全項目の値は **[PRESET_VALUES.md](PRESET_VALUES.md)** にあります。
- 木を選んでいる間は、その木の設定を表示・編集します。選んでいないときは、次に「木を生成」で作る木の設定（ひな形）です。

## 2. パラメータ全項目

「表示場所」は、第 1 章のパネル名です。`—` は画面に出さず、プリセット（JSON）と書き出しでだけ扱う項目です。

## 5. 品質レベル

「品質」（`quality`）で、メッシュの細かさと各種の上限が決まります。上限を超える場合は、細い枝（L3 → L2）から間引きます。

| 項目 | プレビュー | 標準 | 高品質 |
|---|---|---|---|
| 枝の最大段数 | 2 | 3 | 3 |
| 幹・枝の三角形の上限 | 30,000 | 200,000 | 1,200,000 |
| 葉インスタンスの上限 | 20,000 | 150,000 | 1,500,000 |
| L3 の枝の本数の上限 | 0 | 2,200 | 40,000 |
| 断面の頂点数（幹（太いほど増える。これは最小値）） | 12 | 24 | 48 |
| 断面の頂点数（L1） | 6 | 10 | 16 |
| 断面の頂点数（L2） | 4 | 6 | 8 |
| 断面の頂点数（L3） | 3 | 4 | 5 |
| 節の刻み（幹） [m] | 0.5 | 0.25 | 0.15 |
| 節の刻み（L1） [m] | 0.5 | 0.25 | 0.2 |
| 節の刻み（L2） [m] | 0.25 | 0.12 | 0.25 |
| 節の刻み（L3） [m] | 0.12 | 0.06 | 0.12 |
| 幹の断面の弧長の目標 [m] | — | 0.12 | 0.03 |
| 幹の断面の頂点数の上限 | 12 | 96 | 256 |

高品質は三角形の予算を、細い枝の節の刻みではなく枝の本数に回しています。そのため L2・L3 の節の刻みは、標準より粗くなっています（枝 1 本あたりの滑らかさより、枝の本数を優先）。

## 6. プリセットの書式

同梱プリセット（`tree_forge/presets/*.json`）は節ごとに分けた形式で、読み込み時に上の内部名へ変換されます。ユーザープリセット（「プリセットを保存」）は、内部名をそのまま `params` に持つ平坦な形式です。

| JSON のキー | 内部名 | 項目 |
|---|---|---|
| `measured.height_m` | `height_m` | 樹高 |
| `measured.dbh_cm` | `dbh_cm` | 胸高直径 |
| `measured.crown_width_m` | `crown_width_m` | 樹冠幅 |
| `crown.shape` | `crown_shape` | 樹冠形 |
| `crown.base_ratio` | `crown_base_ratio` | 枝下高比 |
| `leaves.type` | `leaf_type` | 葉の種類 |
| `leaves.length_cm` | `leaf_length_cm` | 葉身長 |
| `leaves.width_ratio` | `leaf_width_ratio` | 幅/長さ |
| `leaves.per_m` | `leaves_per_m` | 葉の密度 |
| `leaves.cluster` | `leaf_cluster` | 葉のまとまり |
| `leaves.scale` | `leaf_scale` | 葉の拡大率 |
| `leaves.amount` | `foliage_amount` | 葉の量 |
| `leaves.reach` | `leaf_reach` | 葉を付ける枝 |
| `leaves.start` | `leaf_start` | 葉の付き始め |
| `leaves.scatter` | `leaf_scatter` | 葉の散らばり |
| `leaves.max_instances` | `leaf_max_instances` | 葉の最大数（インスタンス） |
| `leaves.fascicle` | `fascicle_count` | 針葉束の本数 |
| `leaves.geom` | `leaf_geom` | 葉の表現 |
| `leaves.scale_var` | `leaf_scale_var` | 葉サイズのばらつき |
| `leaves.flower_density` | `flower_density` | 花の密度 |
| `leaves.evergreen` | `evergreen` | 常緑 |
| `leaves.color` | `leaf_color` | 葉の色 |
| `leaves.autumn_color` | `autumn_color` | 紅葉の色 |
| `leaves.flower_color` | `flower_color` | 花の色 |
| `bark.type` | `bark_type` | 樹皮タイプ（記録のみ） |
| `bark.displace_mm` | `bark_ridge_mm` | 樹皮の凹凸 |
| `growth.*` / `trunk.*` / `damage.*` / `material.*` | 内部名そのまま | 第 2 章 |
| `levels[i].*`（i = 1, 2, 3） | `l{i}_*` | 枝 L1〜L3 |
| `profile` | `profile` | 太さプロファイル（[高さ比, 直径 cm] の配列） |
| `_src` | — | 値の出所の注記（M: 図鑑・DB の記載値 / E: 推定値）。読み込みでは使わない |

樹種プリセット: スギ（`sugi`）、巨大スギ（御神木）（`sugi_giant`）、ヒノキ（`hinoki`）、クロマツ（`kuromatsu`）、ケヤキ（`keyaki`）、ソメイヨシノ（`someiyoshino`）、イチョウ（`ichou`）、イロハモミジ（`iroha_momiji`）、シラカバ（`shirakaba`）、クスノキ（`kusunoki`）、ヨーロッパナラ（`quercus_robur`）、ヨーロッパトウヒ（`picea_abies`）、シダレヤナギ（`shidareyanagi`）。

## 7. 参道シーンのオプション

`tools/build_sando_scene.py`（アドオン本体には入っていません）。`python tools/build_sando_scene.py --out sando.png` または `blender -b --factory-startup --python tools/build_sando_scene.py -- --out sando.png`。

| オプション | 既定 | 選択肢 | 説明 |
|---|---|---|---|
| `--out` | sando.png |  | 出力する画像のパス（PNG） |
| `--view` | wide | wide / low / crown | 構図。wide: 参道の入口から見上げる全景（縦長） / low: 幹の根元近くから見上げる / crown: 樹冠の拡大 |
| `--seed` | 7 |  | 巨大スギの乱数シード |
| `--samples` | 96 |  | Cycles のサンプル数 |
| `--scale` | 1.0 |  | 解像度の倍率（0.5 で縦横半分） |
| `--fog` | 0.0007 |  | 霧の濃さ（0 で霧なし）。濃くすると空が暗くなる |
| `--bg-trees` | 30 |  | 参道沿いの杉並木の本数（目安） |
| `--forest` | 140 |  | 遠景の森の本数 |
| `--hero-quality` | HERO | PREVIEW / MEDIUM / HERO | 巨大スギの品質 |
| `--no-shimenawa` | オフ（付けたときだけ有効） |  | 御神木の注連縄を付けない |
| `--no-shide` | オフ（付けたときだけ有効） |  | 紙垂を付けない |
| `--no-mound` | オフ（付けたときだけ有効） |  | 根元の土盛りを付けない |
| `--no-litter` | オフ（付けたときだけ有効） |  | 根元の落ち葉を散らさない |
| `--no-bark-moss` | オフ（付けたときだけ有効） |  | 御神木の幹の根元に苔を付けない |
| `--no-stubs` | オフ（付けたときだけ有効） |  | 御神木の枝下の枝痕（スタブ）を付けない |
| `--no-extras` | オフ（付けたときだけ有効） |  | 御神木に足したもの（上の全部）を付けない |
| `--save-blend` |  |  | .blend も保存するパス |
| `--no-render` | オフ（付けたときだけ有効） |  | シーンだけ作って描画しない |
| `--no-denoise` | オフ（付けたときだけ有効） |  | デノイズを使わない |

御神木に足したもの（注連縄・紙垂・土盛り・落ち葉）は、`.blend` では `Hero_Extras` の下に項目ごとの子コレクションで入るので、アウトライナーでも切れます。
